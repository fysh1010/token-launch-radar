Token launch radar: rank pre-token DeFi protocols by implied launch value. Built by an AI agent for make.fun's "Build the best token launch radar" bounty, $1,325 in USDC.

The board covers the full 40-protocol watchlist (TVL >= $50M, no token on record) plus 158 pre-token protocols the watchlist does not name: 138 below the floor, and 20 above it that the watchlist skips, flagged OFF LIST. Each row carries three separate numbers, never folded into one another. Launch value is the primary USD valuation and the ranking — and in this release it is the flat TVL multiple, 0.21 × TVL: the strict rolling validation in the dashboard found no blend of the radar formula that beats flat TVL out of time, so the board ranks by flat and the radar formula is kept as an auxiliary valuation per row. The rolling test sorts the 95 traded tokens with a listing date, trains on the earliest 47, and prices the rest in four blocks of 12, each block using only data from before it; the first three blocks pick the blend, the fourth is held out. Pooled median miss across all four blocks: flat ×5.40, α=0.25 ×5.37, α=0.50 ×5.25, α=0.75 ×5.07, α=1.00 ×5.04 — the best blend is only 6.7% below flat, short of the 10% the gate needs, and the held-out fourth block is worse than flat for every blend (×9.05 flat against ×10.94 for the radar formula), so the gate fails and the board uses flat. The radar formula itself is 0.2195 × TVL^0.85 × anchor^0.15, times a growth factor measured against the protocol's own category median (tanh, so spikes saturate) and a chain factor (+3% per extra chain, up to five); the anchor is one definition everywhere: the traded-token TVL median for the row's category, shrunk toward the global median of $32.6M — the board and the holdout use the same anchor. The 0.88 scale is set by the traded tokens' own median raw log error, not by any competitor's total. Tokenization propensity is a logistic score fitted on the 442 eligible protocols — 244 already have a token, 198 rankable pre-token — from log TVL, chain count and the category rate, with the same eligibility filter on both sides. Log age was dropped by ablation: it lifts random-fold AUC (0.70 vs 0.64) but cuts time-split AUC (0.56 vs 0.62) and degrades both halves of the newer set. Propensity is a cross-sectional heuristic, not a calibrated chance of launching: only this snapshot exists, so true future-launch calibration cannot be computed. Out-of-fold quality: ROC-AUC 0.64, Brier 0.23 (0.25 for always guessing the 55% base rate), log loss 0.65 (0.69); by time, fitted before 2025-05-05 and scored after, AUC 0.62 — but Brier 0.35 against a 0.35 baseline and log loss 0.91 against a 0.91 baseline, so the propensity is below baseline on the time split and has no reliable cross-period predictive power, which the dashboard says plainly. The third number is the risk-adjusted score, launch value times propensity — a unitless sort aid, never labelled USD and never called an expected value. The board model is checked out of sample on the 128 traded tokens with nested calibration, so no test sample's own market cap enters its own scale factor: because the board is flat, leave-one-out median miss is ×5.07, the same as flat, and by-time ×5.29, also the same — the scale drifts forward in time (the old half's median log error is 0.00, the new half's +0.29). The nested scale correction belongs to the radar component alone: the radar formula's base is arbitrary and needs it, the flat multiple is already a median, so at alpha 0 the board carries no scale correction. Each row prints a Central 60% model range (P20–P80) from the leave-one-out error distribution, ×0.15 to ×7.03 (P10–P90 ×0.07 to ×14.42); on the by-time held-out caps 62.5% fall inside the printed range and 81.25% inside P10–P90, against nominal 60% and 80% — but per rolling block the coverage is uneven (blocks 2 and 4 cover only 33% in the Central 60%), so the time drift is real and the range is not a promise. Nothing outside the snapshot enters the score, and no protocol name is special-cased. Each row carries a concrete seven-step farm plan with costs and times, a plan state (Category-supported / Conditional / Research first — 5 / 189 / 4), and a Farm / Marginal / Skip verdict judged on each plan size independently under three drop-share scenarios (1% / 3% / 7%); on this board the verdicts are 0 Farm, 64 Marginal, 134 Skip — all 64 Marginal earn it on the $10,000 plan, and no $1,000 plan clears $0 at the neutral 3% share once gas is counted, priced per transaction on its chain: 7 transactions for a 30-day hold ($80.50 on Ethereum, $21.00 elsewhere), 9 for 45 days ($103.50 / $27.00), 11 for 60 days ($126.50 / $33.00). Farm rewards are conditional — assuming the protocol launches and the drop is allocated pro-rata to TVL share — not expected returns. Total implied launch value across the board is $4.35B at a mean propensity of 51%. The dashboard shows the radar-2 versus radar-7 ranking side by side (Spearman 0.99).

## How to read the board

- Rank is launch value, highest first; the bar beside it is the same number scaled to the top row. Tokenization propensity is a cross-sectional score, not a calibrated chance of launching; the risk-adjusted score is launch value times propensity, unitless.
- The board ranks by the flat TVL multiple (0.21 × TVL): the rolling validation table shows why — no blend of the radar formula beats flat out of time. The radar value is shown per row as an auxiliary estimate, never as the ranking.
- Watchlist rows cleared the $50M TVL floor with no token on record; Early rows are the same rule below the floor; Off list rows are above the floor but the watchlist skips them.
- Select any row for the three-number decomposition, the printed range, the farm verdict and plan state, and a seven-step farm plan with costs and times.

## Run it

```sh
node main.ts --input /path/to/snapshot.json --output out
```

`main.ts` reads the snapshot JSON given by `--input`, writes `out/board.json`, the offline dashboard under `out/dashboard/`, screenshots under `out/screenshots/`, and `out/dossier.json`. Node 22, standard library only, no network. Two runs write byte-identical output.
