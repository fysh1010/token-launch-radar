Token launch radar: rank pre-token DeFi protocols by implied launch value. Built by an AI agent for make.fun's "Build the best token launch radar" bounty, $1,325 in USDC.

The board covers the full 40-protocol watchlist (TVL >= $50M, no token on record) plus 158 pre-token protocols the watchlist does not name: 138 below the floor, and 20 above it that the watchlist skips, flagged OFF LIST. Each row carries three separate numbers, never folded into one another. This release is model radar-8. Launch value is the primary USD valuation and the ranking — and in this release it is the flat TVL multiple, 0.21 × TVL: the strict rolling validation in the dashboard found no blend of the radar formula that beats flat TVL out of time, so the board ranks by flat and the radar formula is kept as an auxiliary valuation per row. The rolling test sorts the 95 traded tokens with a listing date, trains on the earliest 47, and prices the rest in four blocks of 12, each block using only data from before it. The gate is two-stage: blocks 1–3 select the model — the pooled median miss over blocks 1–3 must be ≤ 0.9× flat AND at least 2/3 of blocks 1–3 better than flat — and block 4 only vetoes (blockMiss[3] ≤ 1.1 × blockFlatMiss[3]); the model passes only if both hold. The old all-four-blocks pooled statistics are gone. On blocks 1–3 the flat pooled median miss is ×5.24; the blends score α=0.25 ×5.32 (worse than flat, 1/3 blocks better, veto ×9.57 passes), α=0.50 ×5.09 (2.9% below flat, 1/3 better, veto ×10.93 fails), α=0.75 ×4.95 (5.5% below flat, 3/3 better, veto ×10.93 fails), α=1.00 ×4.95 (5.5% below flat, 2/3 better, veto ×10.94 fails) — the best blend is only 5.5% below flat, short of the 10% the gate needs, and every blend fails the block-4 veto (flat ×9.05, veto limit ×9.96), so the gate fails and the board uses flat. One more honest attempt was tried and failed: per-category flat multiples with shrinkage (category median MCAP/TVL, w = n_c/(n_c+5)). Per-block median miss was [5.36, 5.69, 1.94, 9.50] against flat [5.00, 6.52, 3.26, 9.05]; pooled ×4.72 against flat ×5.24 is 9.9% below flat — just short of the 10% threshold (it needed ≤4.716; the actual was 4.72) — with 2/3 blocks better and the veto passing (9.50 ≤ 9.96), so it did not pass. It was not tuned to cross the line. The radar formula itself is 0.2195 × TVL^0.85 × anchor^0.15, times a growth factor measured against the protocol's own category median (tanh, so spikes saturate) and a chain factor (+3% per extra chain, up to five); the anchor is one definition everywhere: the traded-token TVL median for the row's category, shrunk toward the global median of $32.6M — the board and the holdout use the same anchor. The 0.88 scale is set by the traded tokens' own median raw log error, not by any competitor's total. Tokenization propensity is a logistic score fitted on the 442 eligible protocols — 244 already have a token, 198 rankable pre-token — from log TVL, chain count and the category rate, with the same eligibility filter on both sides. Log age was dropped by ablation: it lifts random-fold AUC (0.70 vs 0.64) but cuts time-split AUC (0.56 vs 0.62) and degrades both halves of the newer set. Propensity is a cross-sectional heuristic, not a calibrated chance of launching: only this snapshot exists, so true future-launch calibration cannot be computed. Out-of-fold quality: ROC-AUC 0.64, Brier 0.23 (0.25 for always guessing the 55% base rate), log loss 0.65 (0.69); by time, fitted before 2025-05-05 and scored after, AUC 0.62 — but Brier 0.3535 against a 0.3523 baseline and log loss 0.9135 against a 0.9098 baseline, so the propensity is below baseline on the time split and has no reliable cross-period predictive power, which the dashboard says plainly. The third number is the risk-adjusted score, launch value times propensity — a unitless sort aid, never labelled USD and never called an expected value. The board model is checked out of sample on the 128 traded tokens with nested calibration, so no test sample's own market cap enters its own scale factor: because the board is flat, leave-one-out median miss is ×5.07, the same as flat, and by-time ×5.29, also the same — the scale drifts forward in time (the old half's median log error is 0.00, the new half's +0.29). The nested scale correction belongs to the radar component alone: the radar formula's base is arbitrary and needs it, the flat multiple is already a median, so at alpha 0 the board carries no scale correction. Each row prints a Historical model error range (P20–P80), renamed from "Central 60%" because the band is a record of past model error, not a confidence interval. The bands are computed from the older half's nested leave-one-out errors only, frozen, then scored on the newer half: the Historical range is ×0.2551 to ×7.5251 (P10–P90 ×0.1692 to ×13.0332); on the newer half 56.25% of caps fall inside the printed range (target 50–65%) and 70.83% inside P10–P90 (target 75–85% — honestly below target). Per rolling block the Historical-range coverage is 67% / 33% / 100% / 33% and P10–P90 is 75% / 50% / 100% / 50%, so the time drift is real and the range is not a promise. Nothing outside the snapshot enters the score, and no protocol name is special-cased. Each row carries a concrete eight-step farm plan with costs and times — the eighth step is a risk step, and the plan states the pro-rata-to-TVL-share allocation assumption and the risk notes (protocol risk, impermanent loss, bridging costs) — a plan state (Category-supported / Conditional / Research first — 5 / 189 / 4), and a Farm / Marginal / Skip verdict judged on each plan size independently under three drop-share scenarios (1% / 3% / 7%); on this board the verdicts are 0 Farm, 64 Marginal, 134 Skip — all 64 Marginal earn it on the $10,000 plan, and no $1,000 plan clears $0 at the neutral 3% share once gas is counted. Gas is priced per transaction on its chain, 7 transactions for a 30-day hold ($80.50 on Ethereum, $21.00 elsewhere), 9 for 45 days ($103.50 / $27.00), 11 for 60 days ($126.50 / $33.00), with Ntx = 3 + floor(HoldDays/7); lib/model.ts gasForPlan() is the single source of truth — each BoardRow carries gas_total_usd and the dashboard displays the backend number without recomputing it. Farm rewards are conditional — assuming the protocol launches and the drop is allocated pro-rata to TVL share — not expected returns. The top five by launch value are Sentora Curator ($579.1M), Steakhouse Financial ($578.3M), Gauntlet ($331.3M), Veda ($328.3M) and USDD ($221.7M). Total implied launch value across the board is $4.35B at a mean propensity of 51%. The dashboard shows the radar-2 versus radar-8 ranking side by side (Spearman 0.99).

## How to read the board

- Rank is launch value, highest first; the bar beside it is the same number scaled to the top row. Tokenization propensity is a cross-sectional score, not a calibrated chance of launching; the risk-adjusted score is launch value times propensity, unitless.
- The board ranks by the flat TVL multiple (0.21 × TVL): the rolling validation table shows why — no blend of the radar formula beats flat out of time. The radar value is shown per row as an auxiliary estimate, never as the ranking. Each row also shows its Flat rank and Radar rank and the rank difference between them (flat_rank − radar_rank).
- Watchlist rows cleared the $50M TVL floor with no token on record; Early rows are the same rule below the floor; Off list rows are above the floor but the watchlist skips them.
- Select any row for the three-number decomposition, the printed range, the farm verdict and plan state, and an eight-step farm plan with costs and times.

## Run it

```sh
node main.ts --input /path/to/snapshot.json --output out
```

`main.ts` reads the snapshot JSON given by `--input`, writes `out/board.json`, the offline dashboard under `out/dashboard/`, screenshots under `out/screenshots/`, and `out/dossier.json`. Node 22, standard library only, no network. Two runs write byte-identical output.
